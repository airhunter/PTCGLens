# PTCGLens

PTCGLens 是一个实验性的 Pokémon TCG Live 卡牌识别工具。它从**本机游戏缓存**建立卡图索引，通过**游戏窗口画面**识别卡牌，在游戏旁显示中文阅读浮卡，也可在本机网页中展示整个牌桌的识别结果。

程序只读游戏缓存和屏幕画面，不修改游戏文件，也不连接或注入游戏进程。本项目不是 Pokémon TCG Live 的官方工具。

## 目前能做什么

- 识别对局画面中预设位置的场上卡、手牌和弃牌堆顶卡，并跟随画面检测手牌位置。
- 定位放大的卡牌特写；牌组等非对局页面打开单张卡牌特写时也能识别。
- 监测游戏缓存新增的卡图，增量更新索引、缩略图及卡牌资料。
- 在本机网页中显示识别框、卡牌列表和中文阅读版大图；可切换查看游戏缓存中的原卡图。
- 对当前查询卡牌缺失的中文名称和效果文本提供自动机器翻译，并缓存成功的译文。
- 社区中文缺项时使用完整英文原文绑定的本地参考译文；可导出中文覆盖和缺项报告，见[覆盖记录](docs/chinese-coverage.md)。
- 游戏内按住自定义查询键并悬停在卡牌上，在旁边打开约 350 像素宽的中英双语浮卡，松开关闭；浮卡会锁定本次结果，并自动选择遮挡较少的位置。
- 快捷查询支持从 Decks 等可见卡牌网格定位鼠标下的小卡，并逐卡复核；已用 Decks 和 Card Dex 的真实画面验证，详细记录见[场景回归](docs/query-validation.md)。

**项目状态：原型。** 对局卡位以一张约 16:9 的截图标定，识别结果仍需结合原画面核对。具体边界见[已知限制](#已知限制)。

## 运行环境

- Windows 10 1903 或更新版本，或 macOS 14 及更新版本。Windows 使用 Windows Graphics Capture；Mac 使用 ScreenCaptureKit，需要系统采集和输入权限。实现与验证边界见[跨平台说明](docs/cross-platform.md)。
- [uv](https://docs.astral.sh/uv/getting-started/installation/)；项目依赖由 [pyproject.toml](pyproject.toml) 和 `uv.lock` 管理，Python 3.12、3.13 已验证。
- 本机安装过 Pokémon TCG Live，且游戏缓存里已有卡图和英文卡牌数据库。
- Git，用于获取可选的中文对照表。
- 浏览器，用于打开本机展示界面。

游戏目前无法联网时，可以先准备代码和 Python 环境；**首次建立索引仍需要本机已有的游戏缓存**。仓库不附带游戏卡图、游戏数据库或完整上游中文对照表；包含本项目维护的[本地参考译文补充](translations/README.md)。

## 快速开始

以下命令在项目根目录执行；Windows 使用 PowerShell，Mac 使用终端。

### 1. 准备 Python 环境

```powershell
uv sync
```

`uv` 会按锁文件建立 `.venv` 并安装依赖。后续 `uv run` 会自动检查环境，无需激活虚拟环境。

### 2. 准备中文对照表（可选）

卡名和效果的本地中文对照来自 [PTCGL 中文化项目](https://github.com/Hill-98/ptcg-live-zh-mod)，需单独下载。没有该目录时仍可使用项目自带的参考译文补充和自动翻译，英文始终显示。只获取本项目使用的 `databases_zh-CN` 目录：

```powershell
New-Item -ItemType Directory -Force .tmp | Out-Null
git clone --depth 1 --filter=blob:none --sparse `
  https://github.com/Hill-98/ptcg-live-zh-mod.git .tmp/ptcg-live-zh-mod
git -C .tmp/ptcg-live-zh-mod sparse-checkout set databases_zh-CN
```

Mac 下载中文对照表的对应命令：

```sh
mkdir -p .tmp
git clone --depth 1 --filter=blob:none --sparse https://github.com/Hill-98/ptcg-live-zh-mod.git .tmp/ptcg-live-zh-mod
git -C .tmp/ptcg-live-zh-mod sparse-checkout set databases_zh-CN
```

Mac 可先运行 `uv run ptcglens.py --overlay --check-permissions` 检查屏幕录制、辅助功能与输入监控权限，无需已有索引。授权流程和缓存路径见[跨平台说明](docs/cross-platform.md)。

### 3. 从游戏缓存建立数据

游戏内悬停模式首次启动会自动建立索引，缺少游戏缓存时会等待并显示准备提示，可以直接进入第 4 步。网页模式或希望提前准备数据时，执行：

```powershell
uv run python cache_watch.py --once
```

这一步建立 `output/index/` 特征索引、`output/card-thumbnails/` 缩略图和 `output/card-data.json` 卡牌资料。默认读取当前用户的游戏缓存；缓存位置与默认值不同时，可用 `--cache-root`、`--game-cache` 和 `--translation-root` 指定。命令状态保存在 `output/cache-watch-status.json`。

### 4. 启动实时界面

游戏内快捷查询模式：

```powershell
uv run ptcglens.py --overlay
```

启动后程序驻留在 Windows 系统托盘或 Mac 菜单栏。默认**按住 `Ctrl+Alt`（Mac 为 `Ctrl+Option`），将指针移到卡牌上悬停 0.6 秒查询，松开关闭**。无需点击；允许轻微指针抖动，在已确认卡框内移动不反复查询。持续按住并移到另一张牌时，重新悬停后切换结果。设置提供 0.3–2 秒的悬停时间和自定义快捷键，也可切回原有的组合键加左键/右键点击模式；点击模式仅拦截查询点击。

首次准备、缺少缓存、等待游戏画面时，可从托盘打开“运行状态与准备”，查看当前状态及缓存目录，也可立即检查新卡。未确认卡牌会立即检查缓存；通常每 5 秒增量检查一次，新卡文件尚未写完时短暂等待后继续。保持快捷键按住时，索引更新会自动重新悬停查询；松开或切走游戏后不会重新弹窗。

浮卡展示完整卡面、卡名、HP、特性与招式，中文和英文逐项对应。有本地中文资料时优先显示；缺项自动在后台翻译，英文立即可读，成功译文会缓存。临时网络错误或服务繁忙时每段最多尝试 3 次；松开或换卡会取消后续重试，最终失败仍可阅读英文。没有翻译按钮。长文本在空间不足时可用触控板或滚轮滚动。`中`、`EN`、`译` 标记中文资料、英文和参考译文来源，机器译文不能替代英文规则核对。卡面按下述来源偏好加载。

悬停模式切换应用、游戏最小化或窗口失效时结束本次查看，返回后需重新按键；移入浮卡时保留结果并暂停新查询。关闭按钮或 Esc 也可结束查看。已完成的结果不会随游戏动画自动换牌。松开后的迟到识别、卡图或翻译结果不会重新弹窗。游戏需保持窗口展开，首次启动需要加载本地索引。设置保存在 `output/overlay-settings.json`。

连续查询只保留最新待处理识别。未确认的查询自动在本机保留最近 10 组画面和诊断记录，位于 `output/query-failures/`，不上传。复测入口、内存占用和已验证范围见[稳定性验证](docs/stability-validation.md)。

浮卡按双语内容计算高度，翻译或高清卡图更新后重新布局；空间不足时先等比例缩小卡图、适当扩宽，长文本可滚动，保持文字清晰。默认优先放在游戏内容区域中遮挡较少的位置，并跟随窗口移动和缩放。设置可取消“优先保持在游戏窗口内”。

完整卡图按屏幕缩放保留实际像素；低分辨率图片以原生像素显示，不强行放大。浮卡用 `HD` / `SD` 标记是否满足当前显示尺寸，`中图` / `EN图` 标记卡面语言。默认在后台依次尝试**规则与插画一致的简中卡面 → 同一英文印次的在线高清图 → 本地游戏缓存**。简中样本为 300×419，英文高清样本为 600×825；简中图片不一定达到高 DPI 下的高清尺寸。托盘设置提供“优先简中卡面”“优先英文高清原卡”“仅本地游戏缓存”三种选择。

首次在线查询会下载约 25 MB 的简中目录，再按需下载卡图，保存至 `output/card-sources/`；识别先显示本地结果，图片准备好后自动更新。已验证的对应关系可离线复用，失败请求在本次运行中间隔 5 分钟重试。可见浮卡每 3 秒检查图片更新。下载只请求卡牌目录、编号和图片，不上传截图或游戏画面。简中卡面下方显示其实际系列及收藏编号，与游戏英文印次可能不同；不会仅凭同名替换。匹配规则与覆盖边界见[卡图来源](docs/card-image-sources.md)。这部分目前用于原生浮卡，网页模式仍使用本地资料。

需要整个牌桌的实时总览时，在项目根目录的终端中运行网页模式：

```powershell
uv run ptcglens.py
```

打开 [http://127.0.0.1:8765](http://127.0.0.1:8765)。这个入口会同时启动实时识别和网页服务，并在按 `Ctrl+C` 时一起关闭。默认直接采集游戏窗口；切到浏览器、游戏被遮住时仍可收到游戏输出的新画面。单屏使用建议把游戏设为窗口或无边框窗口模式，避免切换应用时被系统最小化。游戏未启动时识别进程会等待，重新打开游戏后继续。游戏最小化时暂停采集；停止渲染或画面不变时，网页保留最后的识别结果。网页服务默认只监听 `127.0.0.1`。可用 `--port` 修改端口；缓存位置与默认值不同时，可传入 `--cache-root`、`--game-cache` 和 `--translation-root`。Windows 窗口采集不可用时，可用 `uv run ptcglens.py --capture-mode screen` 切回前台截屏；Mac 的该选项仍按目标窗口采集。

## 怎么使用

在对局画面中，网页会展示识别到的卡位。点击识别框或右侧卡牌列表，可打开中英双语阅读版大图，并切换至游戏缓存原卡图。在牌组等其他页面打开单张卡牌特写时，网页会单独识别并展示这张牌。

双语阅读版使用本地原卡插画与文字资料重新排版，**不是官方中文印刷卡面**。有本地简中对照时优先显示，同时保留英文原文；当前查询卡牌缺失中文名称或效果时，自动将对应英文发送给 [MyMemory 翻译接口](https://mymemory.translated.net/doc/spec.php)，标记机器译文，并将成功结果缓存至 `output/translation-cache.json`。翻译需要联网；接口不可用时会提示错误，英文原文仍可阅读。屏幕截图和整张卡图不会发送给该接口。

网页画面只来自 PTCGL 窗口。切到浏览器后，窗口采集仍会接收游戏输出的新画面；如果游戏停止渲染或画面暂时没有变化，网页保留最后一帧并显示“等待游戏新画面”。单独运行的热键抓图命令仍要求游戏在前台。

## 其他命令

| 用途 | 命令 |
| --- | --- |
| 游戏运行时持续检查新增卡图 | `uv run python cache_watch.py` |
| 从已有截图检测多个对局卡位 | `uv run python battle_multi.py search --screenshot <截图路径> --adaptive-hand --adaptive-preview` |
| 搜索一张截图中的放大卡牌 | `uv run python cache_search.py search --screenshot <截图路径>` |
| 使用热键抓取前台卡牌特写 | `uv run python live_capture.py watch` |
| 列出可见窗口以排查游戏窗口标题 | `uv run python live_capture.py windows` |

热键模式中，鼠标位于前台游戏客户区时按 `Ctrl+Alt+L` 抓图，按 `Ctrl+Alt+Shift+Q` 退出。单帧识别使用 [battle_layout.sample.json](battle_layout.sample.json) 中的实验性卡位布局；结果写入 `output/`。

## 已知限制

- 只识别这台电脑已缓存的英文卡图；未下载的印次无法从本地索引匹配。
- 固定场上卡位按一张 1910×1075 的对局截图标定。手牌和放大特写可动态定位，但其他分辨率、桌面布局和动画效果仍需更多实测。
- 严重遮挡、背面朝上，或从未露出可辨识内容的牌无法可靠确认；动画中离开固定卡位的小卡也可能漏识别。
- 游戏内查询对可见网格先定位卡框并复核小图，其他场景用 SIFT 定位覆盖鼠标点的卡图，失败时尝试对局卡位匹配。网格定位基于实际轮廓和行列，不保证所有页面、重叠卡牌及特效遮挡都能确认；低分辨率的局部卡面仍可能显示“待确认”。浮卡在屏幕空间不足时可能部分遮挡原牌。
- 相似度和“待确认”状态不是经过校准的概率。不同印次共用卡图时，可能无法仅凭截图区分。
- 中文对照覆盖不完整。机器翻译可能误译卡牌专有名词或规则文本，不能代替原文核对。

## 数据与来源

可选的本地中文卡牌资源包放在 `local-resources/中文卡牌图片资源包_2025060501.asar`。该文件约 5.23 GiB，包含 8,371 个按游戏卡牌 ID 命名的 Unity 资源，保留用于后续提取和验证离线中文卡面；目前程序尚未读取此包，运行项目无需准备它。卡面清晰度、中文覆盖和匹配兼容性仍待验证。`local-resources/` 已加入 Git 忽略规则，资源包需自行提供，不随仓库分发。

`output/`、`.tmp/` 和本地依赖目录均被版本控制忽略。仓库不分发游戏截图、卡图、游戏数据库或中文化项目的数据。中文对照表由用户自行从 [PTCGL 中文化项目](https://github.com/Hill-98/ptcg-live-zh-mod)取得；该上游仓库标注为 GPL-3.0。原生浮卡按需下载的简中卡面来自 [PTCG-CHS-Datasets](https://github.com/duanxr/PTCG-CHS-Datasets)，英文高清图来自 [TCGdex](https://tcgdex.dev/assets)，均留在用户本地缓存。卡牌及游戏素材的权利归其各自权利人所有，源码许可证不包含这些素材。

资源包来源说明：本地 `.asar` 的名称与格式符合 [Hill-98/ptcg-live-zh-mod](https://github.com/Hill-98/ptcg-live-zh-mod) 中文化模组使用的独立卡图资源包。[上游安装指南](https://xtgs.mivm.cn/guide/get-ready/Windows/HowToInstallTheCHS)提供网盘下载入口，并注明中文卡牌图片资源包由 Kuyo 加速器提供；上游仓库说明卡图来自网络。尚未取得本地 `2025060501` 文件的原始下载记录或上游校验值，因此其具体发布版本与下载来源仍待确认。模组源码的 GPL-3.0 许可证不代表卡图素材也采用该许可证。

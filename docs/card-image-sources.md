# 卡图来源与显示

## 已实现的加载流程

截至 2026-10-04，原生快捷浮卡已接入在线卡面。识别立即显示本地资料及缓存卡图，独立图片线程依次尝试：

1. 规则及插画一致的简中完整卡面。
2. 同一英文系列、编号且规则及插画一致的在线高清卡图。
3. 本地游戏原图或缩略图。

托盘设置可改为优先英文高清或仅用本地缓存。新查询编号隔离旧图片结果；过时请求停止后续下载。单次网络操作最长等待 8 秒，取消不会中断已经进行的网络调用，识别队列不等待图片线程。失败后在本次运行中对同牌、同偏好间隔 5 分钟重试。

## 来源和匹配

文字对照仍来自 [PTCGL 中文化项目](https://github.com/Hill-98/ptcg-live-zh-mod) 的 `databases_zh-CN`；本项目只加载其中的文字 JSON。

简中卡面来自 [PTCG-CHS-Datasets](https://github.com/duanxr/PTCG-CHS-Datasets) 的 `ptcg_chs_infos.json` 与 `img/`。目录首次下载约 25 MB，卡图按需下载。简中编号与 PTCGL 英文资源 ID 不同，名称只能用于检索候选。

- 宝可梦要求中文名称、HP、特性和招式数量、名称、伤害、能量费用和效果文字一致。缺少可靠中文效果对照时不猜测。
- 训练家要求中文效果一致，或命中人工核对过的中英文效果哈希对照。当前 `card-image-rules.json` 仅补充高级球和极限腰带；其他卡不会套用这两个对照。
- 再用 SIFT 对比插画区域；同名、同效果的异画不能仅凭文字替换。优先普通系列卡，赛事标记和促销卡排在其后。
- 记录并展示实际简中系列和收藏编号，不能声称它就是游戏中的同一印次。

英文高清图来自 [TCGdex 卡牌接口](https://tcgdex.dev/reference/card) 和 [图片接口](https://tcgdex.dev/assets)。映射英文系列及编号，核对接口返回的系列 ID、卡牌 ID、名称、HP、招式、费用和效果，再检查插画。未知特殊系列或资料不一致时保留本地卡图。

## 缓存和清晰度

在线目录、图片和已验证的对应记录保存在 `output/card-sources/`，不随 Git 提交。对应记录绑定卡牌规则、人工对照表、匹配版本和来源偏好，变更后重新核对；已验证记录可离线使用。当前目录保留下载时的快照，需要更新数据集时可删除该目录内的 `ptcg_chs_infos.json` 并重启。

用户此前的高级球仅缓存 171×240 的缩略图，被放大后模糊。现在按实际显示器像素比例缩放，设置 QPixmap 像素比例；低分辨率图不放大，完整保留卡面。`HD` 表示满足当前目标显示尺寸，`SD` 表示不足。

- 当前核对的简中图片为 **300×419**，英文高清图片为 **600×825**；简中图片并不保证满足高 DPI 下的目标尺寸。
- 本地缓存根据原资源路径、大小和时间失效；新增原图可取代缩略图。
- 可见浮卡每 3 秒检查图片更新，内容不变时不重新绘制。
- 在线请求不发送截图或游戏画面，只获取目录、卡牌资料及图片。

## 验证及边界

已用高级球 `sv4-5_en_091` 验证普通简中卡面 `CSV1C 112/127`，极限腰带 `sv5_en_154` 验证 `CSV9.5C 179/208`，利欧路 `me1_en_076` 验证同一英文印次 `me01-076` 的高清图回退。已在 125% 显示缩放下渲染核对整张卡面及文字布局。

这些样本不能代表整套牌库覆盖。中文措辞差异、缺少翻译、特殊系列编号或不同插画都会导致回退；当前不借助机器翻译建立卡面对应关系。新版本实际游戏点击效果仍需用户确认。

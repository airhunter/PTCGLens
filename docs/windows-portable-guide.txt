PTCGLens Windows x64 便携测试版

使用前准备
需要 Windows 10 1903 或更新版本的 64 位系统，以及本机 Pokémon TCG Live 的卡图和英文资料缓存。
本包包含运行所需 Python 和依赖，无需安装 Python、uv 或开发工具。

启动
1. 先将整个 ZIP 解压到一个普通目录；不要只复制 EXE，也不要直接在压缩包内运行。
2. 双击 PTCGLens.exe。旁边的 _internal 文件夹必须保留。
3. 运行状态窗口会显示准备进度；首次使用可能需要从游戏缓存建立索引。
4. 游戏展开后，按一下 Ctrl+Alt 开启查询，松手后把鼠标放在卡牌插画上约 0.6 秒。
5. 移到另一张牌并停稳可换牌，再按 Ctrl+Alt、按 Esc 或关闭浮卡可结束查询。
6. 右击系统托盘 PTCGLens 图标可调整快捷键、悬停时间和卡图来源。

退出
从托盘菜单或运行状态窗口选择“退出 PTCGLens”，也可双击 Exit-PTCGLens.cmd。
有系统托盘时，关闭状态窗口只返回后台。再次启动会打开已有实例的状态窗口。

用户数据和升级
设置、译文、索引、卡图和日志保存在 %LOCALAPPDATA%\PTCGLens，升级不需要复制这些数据。
升级前退出旧程序，将新包解压到新目录后启动；不要用覆盖正在运行的文件来升级。
本测试包不附带游戏素材、社区中文对照表或任何人的截图、日志、账号配置。
没有社区中文资料时，仍可使用自带参考译文及按需自动翻译；英文始终保留。

诊断
双击 Self-Check.cmd 可检查资源、图像处理、Qt、原生采集库和证书；自检不采集屏幕。
报告：%LOCALAPPDATA%\PTCGLens\diagnostics\portable-self-check.json
运行日志：%LOCALAPPDATA%\PTCGLens\logs\overlay.log
如果启动失败，请保留自检报告和日志，说明 Windows 版本、显示缩放和具体操作。

本包为未进行代码签名的本机测试版。独立包的实际游戏表现仍需复测。
本机自检不能代表另一台未安装 Python 的干净机器已验证。
源码和项目许可证：https://github.com/airhunter/PTCGLens（GPL-3.0-only）
构建信息：build-info.json；第三方许可：_internal\third-party-licenses。

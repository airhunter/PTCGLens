### 跨启动复用参考特征

### 撤除干扰窗口切换的诊断进程派生

后续进程外原生采样 `window-final/native-stall-1793197659.txt` 显示主线程在 AppKit 的窗口/持久状态检查中等待 Objective-C 关联对象锁；同时，忽略目录的观察脚本从后台线程调用 `subprocess.run(ps)`，采样中可见 `fork`、`_pthread_atfork_prepare` 及相关锁等待。因此撤掉 GUI 进程内部的资源子进程采样，后续直接启动正式入口，资源及原生栈采样只在独立进程执行。此前受这种诊断影响的全屏切换延迟不能直接归咎于正式版本，但用户报告的恢复失败仍需重新验证。

正式程序在刷新可选中文资料时也会通过外部 Git 命令取得来源版本。改为只读 `.git` 的 HEAD、松散或打包引用以及 worktree 的 `gitdir`/`commondir`，避免 GUI 后台派生子进程；缺少或损坏元数据仍只省略可选版本标记。依据 [Git 仓库布局](https://git-scm.com/docs/gitrepository-layout)；[Python 文档](https://docs.python.org/3/library/os.html#os.fork) 也说明多线程与 macOS 系统库组合下的 fork 风险。该功能不覆盖可选的 reftable 引用存储，无法读取时返回无版本标记，不影响卡牌资料。

Python 3.12、3.13 均通过 199 项测试，网页双语测试通过。新增普通分支、打包引用、游离 HEAD、worktree 共享引用和无效元数据检查。

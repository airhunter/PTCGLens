## 覆盖与复测

资料重建后，本机 575 张已索引卡的卡名、674 个招式/能力名、500 条特性/招式效果和 136 条训练家/能量效果仍无中文缺项。重复原文共用同一译文，所以效果字段数与独立译文条数不同。未收录的新规则继续保留英文与按需翻译。

五张受措辞修改影响的卡在 125% 缩放、700×650 逻辑像素可用范围下做离屏内容边界检查：均保持 350 宽，高度 275–300，文字完整且无滚动条。这是布局尺寸验证，不代替中文内容的玩家审校。

`output/translation-review.json` 和 `.txt` 保存本机逐条英文/中文对照与使用卡牌 ID，不随源码分发。执行 `uv run python card_data.py` 重建资料与覆盖报告；本轮代码和浮卡逻辑的验证见[场景回归](query-validation.md)。纠错必须核对完整英文，不能仅按卡名或招式名套用译文。

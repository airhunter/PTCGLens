# PTCGLens v0.1.0-alpha.1 · 首个测试版

这是首个双平台测试版，供收集兼容性和使用反馈。当前先保留为草稿，尚未公开发布。

| 下载文件 | 适用环境 |
| --- | --- |
| `PTCGLens-0.1.0-alpha.1-windows-x64.zip` | Windows x64；项目目标 Windows 10 1903+ |
| `PTCGLens-0.1.0-alpha.1-macos-arm64.zip` | Apple Silicon Mac；项目目标 macOS 14+；没有 Intel 包 |
| `SHA256SUMS.txt` | 两个 ZIP 的 SHA-256 校验值 |

解压后启动 Windows 的 `PTCGLens.exe` 或 Mac 的 `PTCGLens.app`，无需安装 Python 或 uv。Windows 请完整保留 `_internal` 目录。

## 本版功能

- 按一下 Ctrl+Alt（Mac：Control+Option）开启查询，松手后悬停卡牌，移动到另一张牌换牌，再按一下关闭。
- 中英双语浮卡，支持长文本滚动、中文卡面／英文高清图／本地缓存来源及缺项自动翻译。
- 状态窗口与托盘／菜单栏入口、单实例启动、退出、用户数据与程序目录分离。
- Windows 中文路径卡图写入修复、卡牌特写与小牌识别优化、取消查询后的迟到结果隔离。
- 随包运行时、自检入口、构建来源及第三方许可。

## 使用条件与验证边界

- 需要本机 Pokémon TCG Live 已有卡图及英文资料缓存。包中不附带游戏素材、用户截图、个人设置或完整社区中文对照表。
- 首次准备索引可能需要等待。设置、译文及卡图缓存保存在系统用户数据目录，替换应用不会清除这些数据。
- Windows 包尚未代码签名；Mac 包仅 ad-hoc 签名，尚无 Developer ID 签名及 Apple 公证。Mac 首次系统授权需用户自行完成。
- 双平台源码自动测试和冻结包自检用于核对依赖、资源及启动路径；不能代替独立包游戏实战及未安装 Python 的干净机器验证。
- Windows 源码版已有一轮用户人工验收；本版冻结包的游戏内实测、更多系统版本、多显示器与显示缩放仍待扩大验证。离线回退测试按用户要求跳过。
- 机器翻译仅作参考，英文原文始终保留。

反馈时请提供系统版本、芯片／架构、显示缩放、卡名、发生时间及相关自检／日志片段。日志可能含本机路径，请自行检查后再分享。

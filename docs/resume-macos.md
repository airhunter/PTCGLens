## 已落地修复

1. 高清卡图在后台解码为独立 QImage，界面仅执行 QPixmap.fromImage。真实金鱼王 PNG 的旧界面加载路径独立复现约 11.2 秒，新界面转换约 1.4 毫秒；这不是整次识别耗时。
2. 失败来源按文件指纹延后重试，前台窗口校验复用有时效的后台快照。
3. Mac 查询关闭时不初始化原生采集；窗口枚举初始化允许后台等待 15 秒，单帧预算保持原值。延迟首帧只重试仍有效的当前会话。
4. 参考特征持久缓存于 `output/index/compact/`，绑定像素、源元数据及配置/库版本，支持损坏或不可写时回退。1209 张卡首次准备约 206 秒，再读约 22 秒，第二轮 SIFT 调用为 0；不含全部启动步骤。
5. 可选上游 Git 版本改为读取本地 Git 元数据，GUI 后台不派生 Git 子进程。

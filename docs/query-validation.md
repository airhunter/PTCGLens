# 快捷查询场景回归

## 样本与复测方式

`tests/scenes/query-cases.json` 保存场景名称、点击坐标、预期卡名及用于核对规则的英文卡牌 ID，不包含图片。原始截图留在被 Git 忽略的 `output/query-scenes/` 中，分别为 `decks.png`、`current.png`、`previous.png`、`closeup.png`、`belt.png`、`card-dex.png`、`card-dex-720.png`、`battle-720-stability.png`。最后两张是实际 1280×720 游戏画面。

复测使用本地卡图索引及 `output/card-data.json`，不启动鼠标钩子、不点击游戏、不联网获取图片：

```powershell
uv run python query_regression.py
uv run python query_regression.py --scene decks --scene card-dex
```

可用 `--sample-root` 指定截图目录，`--cases` 指定自己的标注文件，`--scales` 覆盖所有场景的比例。默认六组历史截图使用四个比例；实际 720p 画面按标注中的 `scales: [1.0]` 测试原始画面。没有本地截图或预期规则资料时明确报错，不将缺失的样本记为通过。存在未确认或错误答案时退出码为 1；具体结果仍写入 `output/query-regression.json`。

报告记录截图、标注、索引及卡牌资料的 SHA-256；逐点保存结果、候选印次、规则核对结果及识别耗时。即使卡名相同，只要规则与标注印次不同，也记录为错误答案。实际匹配到同规则重印卡可以通过。

## 本轮修正

- **网格小图**：从轮廓及重复行列定位卡框，颜色和结构对比筛选最多 8 个候选。将参考卡面调整到观察尺寸后提取 SIFT，减少高清参考与小图的尺度差异；要求至少 25 内点、0.65 内点比例、匹配点分布及卡框几何一致。轮廓中数量圆标造成的高度延伸按卡宽恢复。不同规则的候选仍待确认。
- **普通小图及局部卡面**：全库检索证据不足时局部重采样，沿用原确认条件。对已有对局卡框可进一步做同尺度模板复核，允许下沿在画面外。
- **重印卡**：仅忽略英文规则的空格和换行差异；卡名、HP、招式、能量费用、伤害符号与效果措辞保留。同名同规则印次在 SIFT 比较中合并，其他规则仍参与竞争。不同属性的基础能量不会因缺少效果文本而被合并。
- **720p 手牌**：平滑宽度按画面尺寸调整，避免把五张手牌连成一张宽框。
- **画面下沿截断**：根据触及下沿的轮廓或两条竖边恢复卡框，再用模板验证；不会仅凭边框输出卡牌。
- **基础能量**：同几何候选增加可见卡面的色相复核，排除共享边框的其他属性。弱几何证据不会仅凭颜色被确认。
- **大特写及控件遮挡**：大卡面复核时限制采样宽度到 220，避免参考缩略图被过度放大而失去尺度对应；真实网格允许只有一行完整卡牌可见。最右侧卡框与翻页控件连接时，从同一行其他卡牌恢复宽度。非基础能量候选必须在插画区域有分散的匹配点，共享边框与规则区文字不足以确认其他插画。
- **快速连续查询**：跳过排队中的旧查询；运行中的旧识别结果、错误、卡图和译文完成后再次核对查询编号。UI 继续核对编号，防止晚到结果替换新卡。

## 现场确认及边界

2026-10-04，用户确认 Decks 的浮卡显示正确，并确认 Card Dex 六尾、莱希拉姆的名称、招式和位置正确。游戏窗口客户区从 `(241,190)-(2161,1270)` 移至 `(404,187)-(2324,1267)` 后完成 Card Dex 的现场确认。现场日志中 Decks 的 4 次查询到界面更新为 475–597 ms；Card Dex 的 4 次查询为 256–459 ms。这些是同一台机器的少量样本，不代表其他电脑的性能。

离线样本含 Decks 12 张小卡、Card Dex 14 张卡、对局出战/备战/弃牌堆顶/局部手牌、完整特写及空白和卡背负样本。按 0.667、0.8、1、1.333 四个比例缩放截图。缩放截图不能代替在游戏中改变分辨率、窗口比例及 Windows 缩放的测试。

当前 88 项自动测试通过，覆盖网格选择、断开及控件连接轮廓、同图不同规则、共享边框不同插画、基础能量颜色、局部卡面、大特写尺度、720p 手牌分隔、真实线程中的新旧请求交错，以及已有浮卡与窗口坐标功能。另覆盖中文资料更新、原子读写、队列内存与诊断失败。真实截图回归的最新结果保存在本地报告中；不能据此宣称所有卡牌和分辨率都通过。

上一轮的 3 张未确认样本（基础斗能量、极限腰带局部手牌、烈焰鸟）已修正并保留在回归中。扩大验证时又遇到月石大特写、阿罗拉椰蛋树及实际 720p 右侧樱花儿的漏识别，均保留为检查点。实际 720p 截图的 14 张卡及 2 个负样本已全部通过离线查询。

最新完整回归：**259 次，259 次通过，0 次错误答案，0 次未确认**，包括六组历史场景的 228 次检查、真实 720p Card Dex 的 16 次检查，以及新增真实 720p 对局的 15 次检查。新增对局覆盖出战、备战、弃牌堆顶、局部手牌、卡背与空白。识别耗时 P50 为 **425.7 ms**、P95 为 **939.0 ms**；报告保存在本地 `output/query-regression-stability.json`。突发查询与实际窗口移动的检查见[稳定性验证](stability-validation.md)。

用户确认原分辨率下连续查询正常；实际 720p 的修正版浮卡内容及位置仍待现场复测。不同窗口比例、更多 Windows 缩放及长时间使用尚未全面验收。

离线识别耗时不含初始化索引、鼠标事件排队、浮卡渲染或联网卡图下载；不能与点击到显示的现场数值直接混用。

## 本次尺寸与位置修正的验证

- 单元测试覆盖长文本超过 620 高度无滚动条、翻译后自动增高、小窗口适当扩宽、游戏窗口偏移、125% 显示缩放、负坐标显示器及移动/缩放后的卡牌锚点。
- 修正图片缩放后重新选取本地数据库文字最长的 8 张牌渲染核对；宽度均保持 350，高度为 657–766，内容无需滚动。该结果针对 840 逻辑像素可用高度及这组样本；低分辨率图按原生像素显示，完整保留卡面。
- 31 项自动测试通过；覆盖浮卡交互及文案、相似印次复核、图片在 125% 显示缩放下保留物理像素、缩略图不放大、高清源替换旧缩略缓存，以及空原图文件夹不会挡住缩略图缓存。
- 在实际显示器配置下只读核对：主屏缩放为 125%，游戏客户区为 `(241,190)-(2161,1270)` 物理坐标，浮卡允许区域映射为带边距的 `(201,160)-(1721,1008)` Qt 坐标。窗口偏移会同步反映到浮卡摆放范围。

正常入口：`uv run ptcglens.py --overlay`。浮卡默认优先留在游戏窗口的可见客户区，托盘设置中可调整这一偏好。

## 极限腰带手牌漏识别修正

- 用户截图同时存在特写及下沿不完整的手牌。全库 SIFT 产生 21–22 个指向手牌的有效匹配点，原确认阈值为 25，因此显示待确认。两个相似印次参与匹配，分散了匹配点。
- 保留全库候选检索及确认门槛。对弱候选，仅取鼠标所指卡框内的特征做逐卡复核，要求至少 25 个内点、0.6 内点比例、匹配点空间分布及相同几何位置；候选规则不同则不确认。
- 在该截图的 4 个手牌点击位置均确认极限腰带，复核内点 64、比例约 0.94；识别约 100–120 ms，仅为离线识别耗时。两个候选印次的效果原文一致，具体印次仍保留候选集合。
- 已重启程序，游戏内实际点击结果仍待现场确认。

## 后续顺序

0. 简中完整卡面、同一英文印次高清图及本地缓存回退已接入；已验证高级球、极限腰带、利欧路样本，仍需扩大规则对照覆盖和游戏内验收。详见 `docs/card-image-sources.md`。
1. 先完成快捷查询的场景验收：牌库密集缩略图、重叠手牌、局部卡面、相似印次，以及不同分辨率、窗口位置和显示缩放。收集失败画面并形成可重复回归样本，错误印次不能输出其他规则。
2. 补齐快捷查询体验：记录点击到内容可读的实际延迟，核对中文数据和按需翻译覆盖，自定义快捷键与连续查询需现场验证。
3. 快捷模式稳定后，再实现另一种原生条状总览，按对方/我方及出战、备战、弃牌等区域分组，并复用同一浮卡组件。现有网页总览不能算该原生目标已经完成。

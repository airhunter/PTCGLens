# 游戏内快捷查询：开发与验证记录

最初中断记录日期：2026-10-03。用户随后要求继续，已恢复并完成第一版。

## 当前状态

第一版已完成现场基本验证。正常入口为 `uv run ptcglens.py --overlay`。提交与推送状态以 Git 记录为准。

这里的“第一版”仅指快捷查询主流程。用户随后指出长内容被滚动区域限制、摆放未约束游戏窗口的问题，已继续修正；全部预设目标与本次验证边界见 [实现状态](implementation-status.md)。

已确认：Ctrl+Alt+右键触发、游戏中央利欧路资料正确、手牌幕下力士资料正确，以及 Esc 只关闭浮卡。最后一次现场日志记录：幕下力士点击到界面更新约 304 ms，莉莉艾的决心约 284 ms；较早的利欧路现场查询约 465 ms。这些是当前机器的少量样本，测到 Qt 界面更新，不代表所有卡牌或电脑的响应时间。

窗口切换显隐、更多分辨率、牌库密集小图、自定义快捷键及联网翻译仍需扩大场景测试。

## 已确认的方向

用户倾向于鼠标指向游戏卡牌，按住自定义查询键并点击，在卡牌旁显示约 350 像素宽的中文阅读浮卡，内容包含插画、名称、HP、特性和招式，位置自动避开被查询的牌。第一版优先实现这个模式。自动总览条是讨论过的另一种方案，当前尚未实现。

## 最初中断时已落地的未提交改动

- `pyproject.toml`、`uv.lock`：新增 PySide6，当前环境已安装 6.11.2。
- `overlay_app.py`：原生托盘程序、后台窗口采集、按需识别、中文阅读浮卡、按需翻译、快捷键设置、窗口切换时隐藏浮卡。
- `overlay_input.py`：Windows 低级鼠标钩子，默认 Ctrl+Alt+右键，查询点击拦截并派发识别任务。
- `overlay_model.py`：快捷键解析、屏幕点到截图点换算、浮卡位置避让规则。
- `global_cards.py`：增加 `find_at`，用局部 SIFT 匹配覆盖鼠标点的卡图，允许只显示部分卡牌；保持原有特写查找接口。
- `ptcglens.py`：新增 `--overlay` 入口。
- `README.md`：新增游戏内查询启动及使用说明。
- `tests/test_overlay_model.py`：坐标缩放、屏幕边缘避让、快捷键校验测试。

最初暂停时尚未启动常驻浮层；恢复开发后已启动并在游戏中验证。

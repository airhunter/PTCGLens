# 本地中文补充对照

`local-zh.json` 是本项目维护的参考译文，使用 GPL-3.0-only 许可证。包含 61 条卡名、278 条招式/能力名、261 条效果文字，共 600 条；同一原文可以供多个印次使用。

- 社区中文对照优先，只有缺项时才使用本文件。
- 每条以完整英文原文的 UTF-8 SHA-256 为键；英文规则、数字或能量改变后，旧译文不再匹配。不能按招式名称直接套用效果。
- 本地补充显示 `译` 标记，社区对照显示 `中`。参考名称、表述不保证与官方简中印次相同，也不保证有对应简中卡图。
- 2026-10-06，由代码助手逐条对照了 261 条效果译文及 339 条名称，修正退化、进化触发措辞与塔拉刚、斗子的名称。两名角色有官方中文依据，其余译名未全部核对官方用语；人工玩家审校仍待完成。范围与出处见[规则核对记录](../docs/chinese-rule-review.md)。纠错时须核对原卡规则。
- 新卡未收录时仍保留英文效果与按需翻译按钮。

执行 `uv run python card_data.py` 导出 `output/chinese-coverage.json`，查看当前索引的字段统计、来源和缺项原文。此报告属于本机输出，不随仓库分发。

补充时从游戏数据库取完整英文原文，核对卡名、HP、费用、伤害与效果后，计算 SHA-256。名称分别存入 `names` / `attks-name`，效果存入 `attks-text`。修改后重建资料、核对报告，再运行自动测试与本地场景回归。
